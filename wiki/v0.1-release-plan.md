## 2. 每版本硬性门禁：必须能起服、能运行

> **原则：** 每个 Git tag 发布前，系统必须在约定环境下 **冷启动成功** 且 **主路径可玩**。功能再多，起不来 / 跑不通 = 不得打 tag。

### 2.1 通用门禁（v0.1 → v1.0 每版强制）

| # | 门禁 | 最低标准 |
|---|------|----------|
| G1 | **冷启动** | `LLM_PROVIDER=mock` + `QDRANT_ENABLED=false`：后端 `uvicorn`、前端 `npm run dev`（或文档声明的 start）无致命报错，监听 `:8000` / `:3000` |
| G2 | **健康主路径** | 注册/登录 → 列种子 → 创建会话 → 至少 1 次 `step` → Play/WS 能拿到 snapshot（已登录成员） |
| G3 | **静态 ×3** | 变更集 ruff + 相关 mypy + `tsc --noEmit` |
| G4 | **单元** | `QDRANT_ENABLED=false LLM_PROVIDER=mock pytest tests/ -q` 全绿 |
| G5 | **文档一致** | README（中英）/ CHANGELOG / 本文件与真实行为一致；不承诺未交付能力 |
| G6 | **作者** | commit = Zhongjiang Yao \<yaozj_roger@163.com\>，无 Co-authored-by Cursor |
| G7 | **Tag** | annotated tag push origin；CHANGELOG 去掉 WIP |
